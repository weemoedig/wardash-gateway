Caching & Data Storage

Responses are cached by endpoint. Four data types are stored locally in our database. If data is not yet available, it will be requested from the War Era API, and you're directly contributing to the Gateway systems.

Stored Data Models

These data types are continuously scraped and stored locally

Articles

All paginated articles: daily, weekly, top, and latest. Searchable by category, language, and author.

Events

All events by country and type. Supports filtering by country and event type.

Work Offers

Searchable by user, region, minimum energy, and production type.

Transactions

All transactions with participants: users, countries, military units, and parties as seller or buyer.
